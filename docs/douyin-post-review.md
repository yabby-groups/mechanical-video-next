# 君哥拆机器 · 抖音发布后复盘模板

每条视频按真实可获取的同口径数据填写。未提供、无实际归因或未手工观察的项目填 `null`，并记原因。零值来自平台明确显示零。保留原始数据导出或截图路径及采集时间。

## 作品与数据窗

| 字段 | 记录 |
| --- | --- |

| 抖音作品 ID 或 URL、发布时间和时区 | |
| 实际标题、封面方案、发布时长、简介版本 | |
| 数据起止、采集时间、后台模块刷新时间与时区 | |
| 数据来源及原文件或截图 | |

## 实际指标

| 指标 | 本窗 | 分母或数据定义 |
| --- | --- | --- |
| 播放量 | | 同一作品同一统计窗口的后台播放次数 |
| 平均观看时长 | | 平台原值，单位秒 |
| 2 秒跳出率、5 秒留存率、完播率 | | 分开记录平台原值、后台定义及可用性 |
| 平均观看比例 | | 同窗平均观看秒数 ÷ 实际视频时长，说明是否含复播 |
| 点赞数、点赞率 | | 点赞数 ÷ 播放量 |
| 收藏数、收藏率 | | 收藏数 ÷ 播放量 |
| 评论数、评论率 | | 评论条数 ÷ 播放量 |
| 独立评论用户数 | | 可计数时单列，附平台或去重口径 |
| 本片归因新增关注数 | | 使用平台归给该作品的人数，附时间窗及归因定义 |
| 每千播放归因新增关注 | | 1,000 × 本片归因新增关注数 ÷ 同窗播放量。小红书用观看量时写作「每千观看归因新增关注」 |
| 分享数、分享率 | | 分享数 ÷ 播放量 |

分母缺失或为零时记录 `null`。滚动窗口累计数据附准确相对起止，跨窗口对照前核对定义。账户总体关注数另记为账户背景。实际表现与制作时的预期分别记录。
