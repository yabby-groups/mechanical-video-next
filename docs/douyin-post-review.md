## 导入与创作回流

作品、采集时间、制作输入可核实时，用 `uv run python -m mechanical_video_next.feedback --input observation.json --output <task>/post-publish/<platform>-<snapshot>.json` 导入现有账本。使用带时区的 `published_at`、`observed_at` 和 `blueprint`、`timeline` 的路径及 SHA-256。可核实上传版时提供 `published_media`；未知时留空，增长报告保留这条记录并仅按相同 SHA-256 归属版本。平台诊断用 `diagnosis` 的 `finding`、`source`；待验证改动用 `hypotheses` 的 `change`、`basis`、`measure`。保留作品归因关注 `attributed_followers` 及账户或平台原字段 `new_followers` 的各自口径。比率使用 0–1。

Producer 读取报告或原始交接记录，把选定的创作假设写进下一集 Treatment 和动稿。发布后回填已观察的指标、样本口径和限制。单集入口和元数据不齐的历史作品可直接使用本节的复盘和带依据的创作决定。

## 水龙头诊断与本轮改动

用户转述的抖音后台数据显示，水龙头视频播放 512，较往期下降 42.63%，2 秒跳出率 28.76%，平均播放 10 秒，完播 4.93%。后台建议提升评论、吸粉、知识总结、生活场景关联、实用知识拓展和系列期待。采集时点、对比基准、流量构成、上传文件哈希、5 秒留存和具体互动值尚缺。保留原值，作品归因和互动时间分布记为 UNKNOWN。

| 可验证的创作假设 | 在本轮动稿里的改动 | 发布后观察 |
| --- | --- | --- |
| 前五秒给出一个能看懂的机械关系，有助于观众继续观看 | 滑轨展示全伸时两处搭接，鼠标并列展示正反拨时两路信号的顺序 | 匹配同平台、相似龄期及流量的 2 秒跳出、5 秒留存、平均播放与完播 |
| 生活经验与机械问题紧邻时，更容易引出具体讨论 | 滑轨前段联系全伸后取用抽屉后排的体验 | 评论率、独立评论人数、与后排取用有关的评论主题 |
| 保留实物参照并把看不见的动作讲明白，能支持收藏和系列期待 | 滑轨保留抽屉与柜体并展示传力，鼠标从正反信号回到整机的轴与编码器 | 同平台作品赞率、藏率、作品归因关注及每千播放归因关注 |
| 结尾给出可复述的结果，有助于收束知识 | 滑轨从两段行程回到后排取用，鼠标把辨方向和数信号变化用于网页回拨 | 整片完播、收藏率和能复述核心知识的评论 |

已有双平台复盘中，皂液泵比门把手和开罐器有更高的小红书藏率，抖音赞率、完播和归因关注也更高。同一批抖音数据中开罐器的 2 秒跳出率最低。样本观察提示开头留人和后段兑现要一起验证。现有两篇交接提供同平台快照、作品龄期和本地候选画面，评论率的可比数据仍缺。上述四项假设已进入两条动稿，平台结果待采。 [双平台复盘](plans/operations-growth-review-20261123.md) · [下一题交接](plans/operations-topic-handoff-20261125.md)
