A＝优先做来源与最小动作预检；B＝先验证新增信息／表达差异；C＝复杂度高或当前表现手段未证明可用。优先级沿用11月9日增长补充，不代表资产、许可、原理或制作已通过。

| 题目 | 观看问题 | 必须证明的可见关系 | 优先级与主要预检风险 |
| --- | --- | --- | --- |
| 指甲刀 | 手柄动一大段，刀口只合一点，为什么？ | 实际结构的支点、传力路径与开合量关系 | A，先核实复合杠杆/弹性片，不能无依据夸大省力倍数 |
| 订书机 | 钉脚穿过纸以后，谁把它折弯？ | 同一枚钉受压、穿纸、接触底座后变形 | A，连续跟踪，不能切走最关键折弯瞬间 |
| 晾衣夹 | 手松开后，夹口的力从哪里来？ | 同一弹簧与夹臂在按下/松开时的关系 | B，原题过于显然；有清楚的新关系才独立成片 |
| 美工刀 | 刀片能推出去，为什么不会自己滑回？ | 实际定位件进入/退出卡位与滑动对应 | B，不拼接不同型号的锁止方式 |
| 喷壶 | 活塞来回动，水为什么只朝喷口走？ | 进/出通路与阀件在两程中的交替状态 | A，限定手扣式泵等具体类型；与皂液泵去重 |
| 回力车 | 往后拉，为什么松手却向前跑？ | 轮轴、储能件和传动在两程中的实际关系 | A，齿轮方向与储能机制必须同源 |
| 修正带 | 两个卷盘越来越一大一小，为什么还能一起走？ | 实际收放、张力调节或滑动关系 | A，先查具体机构，不能默认所有产品同构 |

| 手摇打蛋器 | 手摇得不快，搅拌头为什么转得更快？ | 同一输入运动与齿轮/输出的对应 | A，明确传动比依据，不靠动画快放冒充传动 |
| 开罐器 | 只转手柄，刀和罐边怎样一直往前走？ | 夹持、进给轮与切割接触的连续关系 | A，先限定结构，核心接触不能被外壳遮住 |
| 自动铅笔 | 松手时，笔芯为什么没有跟着退回？ | 夹持/释放件与同一笔芯在一周期中的状态 | A，不能只做笔芯平移，避免与按动笔转位混淆 |
| 缝纫机 | 针拔出来了，线为什么还留在布里？ | 同一根上线形成线圈并与底线成线的完整路径 | C，柔性线/旋梭可见性预检先行，不只看针上下动 |
| 门锁斜舌 | 门能把锁舌顶回去，关好后为什么挡得住？ | 限定结构的斜面、复位与受力接触差别 | A，只解释结构，不扩展为绕锁操作 |
| 自行车飞轮 | 不踩时轮子还转，为什么脚踏不用跟着转？ | 同一参照下传力与空转路径 | B，与棘轮题重复风险；需不同用途与新证据 |
| 自行车变速器 | 换挡时链条长度没变，多出的部分去哪了？ | 导轮臂变化与链路长度/张紧关系 | A，先回答收链，不扩展一整套变速知识 |
| 雨伞 | 推动一个滑块，整圈伞骨为什么一起展开？ | 同一组连杆铰接从收拢到展开 | B，多杆遮挡、布面与骨架关系先验证 |
| 皂液泵 | 每次松手，下一泵液体怎样补上来？ | 泵腔容积变化与单向阀切换 | B，喷壶若已讲同一因果则后移，不换壳复述 |
| 门把手 | 松开后回正，究竟是哪一处在拉回？ | 把手轴、复位件与锁舌的实际对应 | B，与斜舌题按新增关系决定合并或分开，不预设拆成两片 |
| 电水壶 | 蒸汽到了哪里，开关才会跳开？ | 指定型号中蒸汽路径、温敏件与开关动作 | C，电热/材料变化证据先行，不把所有水壶说成同构 |
| 马桶水箱 | 水位升到这里，谁把进水关掉了？ | 同一浮动件与阀门状态的对应 | A，先限定进水阀类型，勿混入冲水阀 |
| 机械定时器 | 发条一直想回去，为什么能慢慢走？ | 储能、调速与触发响铃的实际路径 | C，若不能清楚讲一个关系则拆小范围，不变成零件目录 |
| 旋转拖把 | 手往下压，为什么拖把变成旋转？ | 同一输入行程与螺旋/传动件、回程关系 | A，限定型号，不预设所有产品同一结构 |
| 手摇卷笔刀 | 刀在转，为什么还能绕着铅笔走？ | 选定刀型的自转/公转及进给对应 | A，先查滚刀型等具体结构，不泛化全部卷笔刀 |
