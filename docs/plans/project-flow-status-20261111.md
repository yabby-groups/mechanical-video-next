## 现行流程

1. Producer 用 `python3 -m mechanical_video_next produce` 创建 protocol v2 任务。当前会话为唯一 Producer，最多三个原生子代理；Python 执行确定性工具和校验，不模拟 Agent。
2. 先查本地 references，再做 ViralResearch 创意研究；同题、相似结构、叙事参考按 50%/30%/20%，默认最多 30 候选、10 深析。实际观看与未知项须保留。
3. MechanicalResearch 固定真实结构、连接、尺寸依据、约束与未知。CAD 依此用 build123d/Open CASCADE 生成参数化源码、独立实体、STEP/GLB、装配清单及数值验证。网络资料默认只作研究依据。
4. 先看装配、爆炸、必要剖切和 3—5 秒关键动作诊断；独立机械 QA 核对实际实体、接触、干涉、运动和机制可见性。FAIL/UNKNOWN 不解锁高清动画。
5. Producer 核对可行性、冻结蓝图并编译真实镜头配置，绑定精确路径和 SHA256。低成本动态分镜由独立 QA 审核；静态占位板不能证明机械运动。
6. 动态分镜通过后，才做完整低清预览、独立预览 QA、正式制作与最终 QA。Editor 可准备音频，最终合成等待镜头时间轴；新文案需核对批准范围。
7. 通过 `handoff` 保存不可变版本与依赖哈希，`advance` 检查状态，`stage` 串行执行 Blender 重任务。输入变化使旧批准失效。
8. 完整验收后才能 COMPLETED；发布是另行授权操作。技术解码、截图或响度检查不替代机械、连续视觉和听感验收。

默认视觉为打印机 EP03：全画面机械主体、灰色摄影棚、金属与柔和阴影；保留 Neil 与横屏 1920×1080。规定运动/形变须标“原理示意”，不冒充接触或材料仿真。
