# 「君哥拆机器」制作契约

持续制作准确、好看、易懂的机械拆解与原理视频。每集以一条完整的可播放成片作为交付。选题、资料研究、文案与分镜、模型与动画、配音与字幕、剪辑与混音、成片检查围绕同一条片子推进。

## 选题、文案与画面

- 尊重用户指定的对象和范围。选定可核实的具体型号，用原厂、维修、实物拆检等资料核对外观、装配、关键接触和运动。记录来源和实际查到的范围，给教学简化明确边界。
- 新片采用原创三维机械画面，研究资料排除专利。根据题材选择工作原理（How）、设计原因（Why）、不同设计比较（Compare）、生活实用（Practical）和隐藏发现（Discovery）。有直接依据且能用动作讲清的知识优先。寿命、材料性能、故障归因和维护建议需要与型号及适用条件相符的资料。
- 选题优先考虑熟悉的日用品里鲜为人知的机械现象。研究第一眼能否看见、多久能给出实质发现、后续有哪些新的因果可拍，以及同类题材能否形成观众可辨认的系列。模型和缓存支持表达。
- 旁白、镜头和动作一起编排。用拆解交代零件位置，用有依据的连续三维运动展示关键因果。按需要使用剖视、特写和运镜，让观众看得到操作、传动、结果和必要的回程。一个题材可以讲多个相关知识点。
- 优先检查可复用的同型号资产和许可证。需要建模时沿用 CAD、EAS 或 Blender，保存源文件。其他作者的作品默认用于参考。有复用许可的素材按许可和需要剪入。
- 文案说人话，字幕用实际配音文本。片长随讲解、配音和必要的观察时间决定。采用 1920×1080 横屏、30 fps。

## 从机械现象推进知识

研究时找出具体型号上最有看头的现象、观众平时看不到的结构及可保留的产品识别线索。给第一帧一个明确的观看目标。可以用内外同步、局部透视、状态对照或近景展示真实关系。若用静态整机、慢转台、推进、日常演示或旁白起问，说明它具体提供了哪条值得追看的线索。

开场可直接露出内部动作和局部答案。用 0–2 秒看有价值的现象，2–5 秒看首次实质知识，2–10 秒看首个值得点赞的发现，5–10 秒看三维拆解和讲解怎样建立持续关注的理由，5–15 秒看观众能否自然联想到自己的使用经历或设计疑问。具备更早的表达就提前，同时保留辨认和观察动作的时间。用下一项新发现承接已兑现的答案，沿途给可回看的结构、状态对照或实用知识。结尾通过画面和一句话收束到能复述的知识。确有已确认且未发布的相关选题时才预告具体问题，其余可用本集知识或系列价值自然收尾。

Producer 在现有 Treatment 中为所选知识写清来源、观众带走什么、哪个动作证明、何时兑现。将实际镜头、旁白、可见状态和时间区间写入 Blueprint 或本集剪辑。高清渲染前复用相机、模型、镜头缓存或低分辨率渲染做动态预演。比较原片和候选动稿上的前段发现、讨论场景、留存线索与后段的新知识。静音和手机尺寸有助于确认关键部位的可读性。把选定的机械关系、构图和衔接落实到动画、运镜、配音、字幕和剪辑。参考窗口用于创作取舍，镜头时长由表达决定。

## 制作和交付

当前会话负责完整成片。可将复杂机械核证、CAD、动画或实际视听检查交给现有专长角色。同一问题以已有证据和实际制作文件交接。

新片使用 [README 中的正式入口](../README.md)。该入口读取本集已编排的旁白、镜头与剪辑参数，调用现有 Neil、Blender、Remotion 和 FFmpeg。用实测语音时长安排字幕和镜头，配上清晰可闻的 BGM，按画面需要放入拟音。修改旁白、配乐或画面时复用未受影响的镜头，并检查实际更新的片段和连接处。对确认可再生的中间帧及时编码并清理。

成片检查集中核对机构和科学表达、原创及素材许可、字幕、节奏、音画同步和混音。具备实际视听能力时完整观看和实听。程序检测用于定位问题。记录检查的实际范围，缺少观看或听审能力时提供待人工确认的成片和未验证项。交付成片 MP4 和实际配音文案。封面、报告和平台操作按用户本次需求处理。

观众审核由用户手动调用，只读实际成片。检查两秒、五秒和全片，记录前十秒的实质知识、首个潜在赞评关时点、生活实用知识、内容推进、总结、收藏和系列价值。前两秒的候选改法独立保留。连续感知缺失时按实际覆盖标注 UNKNOWN。

运营复盘以作品、平台和龄期可比的窗口记录两秒跳出、五秒留存、平均播放时长、完播、赞评藏率和本片归因新增关注，分母可用时计算每千播放或观看归因新增关注。用高低指标作品可核实的内容差异与后台诊断提出下一题的创作假设，并记录验证窗口、指标和实际结果。只有后台提供时间分布时，才用相应时间粒度对照成片。沿用 [发布后复盘模板](douyin-post-review.md)。
