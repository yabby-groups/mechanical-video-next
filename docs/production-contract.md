# 「君哥拆机器」制作契约

持续制作准确、好看、易懂的机械拆解与原理视频。每集以一条完整的可播放成片作为交付。选题、资料研究、文案与分镜、模型与动画、配音与字幕、剪辑与混音、成片检查围绕同一条片子推进。

## 选题、文案与画面

- 尊重用户指定的对象和范围。选定可核实的具体型号，用原厂、维修、实物拆检等资料核对外观、装配、关键接触和运动。记录来源和实际查到的范围，给教学简化明确边界。
- 新片采用 **3D 为主、2D 为辅、知识表达优先** 的视觉原则，研究资料排除专利。产品外观、拆解、装配、真实运动、内部空间关系、关键接触、传动、工作过程和产品操作原则上采用原创三维动画。
- 力学、受力、速度和位移、电路、公式、流程、结构对比、抽象原理和总结可用 2D、2.5D、3D 或混合表达。可在三维画面上叠加动态标注、箭头、轨迹、曲线、公式和图形，也可插入独立二维动画，再以共用部件、动作状态或视线方向切回机构。根据知识是否更好懂和实际观看效果选画面，纯三维可独立成片，二维占比无固定要求。核心机械动作须有接触和可见的状态变化，避免幻灯片、静图轮播或长段文字代替机械画面。
- 根据题材选择工作原理（How）、设计原因（Why）、不同设计比较（Compare）、生活实用（Practical）和隐藏发现（Discovery）。有直接依据且能用动作讲清的知识优先。寿命、材料性能、故障归因和维护建议需要与型号及适用条件相符的资料。
- 先找可核证、有视觉反差且能持续推进的机械现象。搜索涵盖传动、精密机构、五金工具、工业和工程机械、汽车交通及精巧日用品。日常熟悉度帮助设计入口，题材价值由实际现象、动作、深度和持续可视化空间决定。确认首个可视化发现、后续专业深度和实用价值能支撑至少 60 秒的正式内容，并考虑原创三维的表达空间、持续互动理由和系列潜力。内容不足时深化有依据的知识、换切入角度或换题。按需优先研究页面可核实精选标记的机械作品，以及粉丝量和播放量有据的同类作品。记录看到的标记、数据时点和实际画面区间，从中提炼如何提前展示发现及推动后段知识。精选状态和观看覆盖缺证时写 UNKNOWN。
- 旁白、镜头和动作一起编排。用拆解交代零件位置，用有依据的连续三维运动展示关键因果。按需要使用剖视、特写和运镜，让观众看得到操作、传动、结果和必要的回程。一个题材可以讲多个相关知识点。
- 优先检查可复用的同型号资产和许可证。需要建模时沿用 CAD、EAS 或 Blender，保存源文件。其他作者的作品默认用于参考。有复用许可的素材按许可和需要剪入。
- 文案说人话，字幕用实际配音文本。正式成片默认至少 60 秒，常规参考 120–180 秒，知识丰富的复杂题材参考 180–300 秒。开场实验、低成本动稿、局部验证、技术测试和用户明确要求的超短片可短于 60 秒。采用 1920×1080 横屏、30 fps。
- 优先保留有证据的设计原因、传动和传力关系、结构对比及实用知识。压缩空洞介绍、重复讲解、重复动作、无效停顿与运镜。保持机械动作应有的节奏，按内容调整旁白、动作和切点，避免靠放慢动作、等配音或延长片头片尾达到时长。

## 从机械现象推进知识

沿用用户给出的抖音精选创作参考。优先让观众读懂有专业深度或实用价值的关系，看到真实的隐藏运动或反直觉现象，并通过三维画面和声音清楚地跟上因果。日常使用、常见疑问和设计取舍提供自然的生活关联。按题材从下列特征选择重点，以实际创作和复看为依据。

- **获得感**来自可以复述、应用或对照的知识。解释为什么选择这种形状、材料或传动方式，以及它如何影响使用、维护或故障。
- **惊喜感**来自平时看不到的真实关系。保留物品参照，通过局部剖视、放大或状态对照让观众亲眼看到变化。
- **表达力**来自清楚的观看目标和连续因果。同步外部操作和内部运动，以构图、材质、光色与镜头衔接区分部件和状态。旁白重音与拟音跟随真正的发现和机械事件。
- **感染力**来自观众认得的日常问题、真实故障或使用体验。关联紧贴机械知识，避免虚构个人经历、煽情与制造争议。

四项特征用于编辑取舍。官方精选结果、平台流量和奖励依据后台实际反馈记录。

研究时找出具体型号上最有看头的现象、观众平时看不到的结构及可保留的产品识别线索。给第一帧一个明确的观看目标。可以用内外同步、局部透视、状态对照或近景展示真实关系。若用静态整机、慢转台、推进、日常演示或旁白起问，说明它具体提供了哪条值得追看的线索。

让首帧视觉中心落在最有发现的机械关系上，同时用产品轮廓或相邻结构给出方位。先露出最强发现的可见现象，后段再补齐接触、导向和因果。镜头变化对应新的观察任务，按需切进剖视、接触特写或在相同方向比状态。用相机跟住真正移动的接触点，用材质粗糙度、边缘高光和接触阴影区分构件。位移、速度或力的标记尽量随真实构件和接触点变化。用 0–2 秒看有价值的现象，2–5 秒看首次实质知识，2–10 秒看首个值得点赞的发现，5–10 秒看三维拆解和讲解怎样建立持续关注的理由，5–15 秒看观众能否自然联想到自己的使用经历或设计疑问。具备更早的表达就提前，同时保留辨认和观察动作的时间。用下一项新发现承接已兑现的答案，沿途给可回看的结构、状态对照或实用知识。结尾通过画面和一句话收束到能复述的知识。确有已确认且未发布的相关选题时才预告具体问题，其余可用本集知识或系列价值自然收尾。

新片在联合时间轴的 `creative` 写明现象、领域与预期受众、创意取舍、已核实的研究，以及实际使用的运营观察、反例和待发布验证的假设。按表达需要比较不同切入角度。数据缺失时记录不确定性并继续创作。通过 `pacing` 和联合时间轴把新增知识、必要观察、实际镜头与声画证据落实到时段。同一动作的必要补看记录其观察目的。高清渲染前复用相机、模型、镜头缓存或低分辨率渲染做动态预演。从头到尾检查新知识能否逐段推进、哪些相关知识应补回、哪些区间可以压缩。关键视觉发现存在表达疑问时做动态对照。用 `opening-analysis --phone-preview` 以原速复看窄屏尺寸的完整动稿，并静音复看关键段落。检查主体占比、机构轮廓、状态差异、视线先到哪里和字幕可读性。把选定的机械关系、构图和衔接落实到动画、运镜、配音、字幕和剪辑。参考窗口用于创作取舍，镜头时长由表达决定。

## 制作和交付

当前会话负责完整成片。可将复杂机械核证、CAD、动画或实际视听检查交给现有专长角色。同一问题以已有证据和实际制作文件交接。

新片使用 [README 中的正式入口](../README.md)。带 `creative` 的剪辑首次执行先生成完整动态预演、真实合成音轨和 384 像素手机版。Producer 读取并复查这些文件，在同一工作目录的 `preview/audience-review.json` 记录前两秒、前五秒、全片推进及修复证据，再执行同一命令进入高清。动稿更改后绑定新 MP4 的复查。历史单集剪辑保留原调用方式。用联合时间轴分别编排画面、旁白、机械动作和声音。让观众在连续动作中从实际使用切到关键接触，或在同一句旁白中进入示意图。按内容给实验和操作留出纯视觉时间。让实测语音安排字幕，给超长旁白改句或调整独立语音区间。拟音来自真实录音、模拟拟音或明确标明的科学示意，起点跟随可见机械事件。修改旁白、配乐或画面时复用未受影响的镜头和已测语音，并检查实际更新的片段和连接处。旧账本按其固定契约恢复。

### 机械检查

1. 建模前，按核心动作拆出影响讲解正确性的机械接口。用原厂资料、实物观察或可信的维修资料列明输入件、相邻件、装配约束、动作方向和中间状态。在 `mechanics-plan.json` 的现有 `claims` 中写出来源位置及可与模型核对的预期。接触机构写明运动方向上的首次接触面、相邻件的自由度，以及受力如何传给下一件。流体机构逐段写明入口、开孔、所在零件边界和出口。按需要覆盖传动、限位、锁止、释放和复位，并标出资料可见范围与教学简化。每镜绑定相关关系、实际场景及依赖、剪辑参数和旁白。外观、纯展示及无机械断言的辅助镜按实际内容记录分类依据。场景或剪辑中的自报分类不作为验收凭证。
2. 核心机械场景保留 `mechanics.evidence`、`scene_inputs` 和 `check_mechanics`。本集的 `mechanics_review.py` 依据独立资料逐接口检查 Blender 求值对象和网格，核对尺寸、形状、朝向、约束及相邻件相对运动中与讲解有关的部分。按构造和接触需要检查完整帧区间及子帧，验证事件顺序和状态保持。到达设定位置只证明该位置，首次接触和传力须用相邻件和中间姿态的证据核对。复用现有 `mechanics.checks` 检查连续切点。正式入口在高清调度前阻止机械 FAIL 和无有效凭证的机械 UNKNOWN。复用核心镜头缓存时，核对现行核证凭证及动态画面。图解核对与资料相符的变量及变化关系。
3. 对最终 MP4 按输出帧对照源区间，再结合画面核对可见接触、旁白、图解、箭头和跳切。像素对照验证组合后的画面是否沿用核证过的动作。Producer 把关键画面的核对记录绑定到实际 MP4 哈希，机器写出对应的 `.mechanics.json`。画面表达缺证的完整输出标为候选片，机械状态为 UNKNOWN。连续观看、实听和独立审片各自记录实际覆盖，缺失时可与机械状态分别保留。

动态预演与成片阶段复用现有 QA 检查实际编码画面和完整工作循环。即使总览没有异常，也按事件观察已登记关键接口的前、中、后状态，并主动找未声明的异常。细节不足时取原尺寸帧并放大局部，按画面位置回查场景、求值对象、几何与驱动。按需使用原相机局部、正交、隔离或透视观察，并重新核实本集型号资料。原厂照片明示的形状、方向与边界可独立核对，例如先判定壳壁窗口和伸出短管的结构差异，再处理内部流路的证据缺口。分别记录已确证错误、已观察到的结构差异、依据充分的教学简化及待核实关系。遮挡或观察能力不足写明影响哪个判断。修复前后按相同相机、区域及对应动作时刻复查实际画面。记录已观察覆盖和疑点。 [机械画面诊断](qa-images.md#机械画面诊断)

检查发现错误时，由 Producer 按机构、镜头时码和场景或剪辑定位根因，修复后重新求值，只重渲受影响的镜头，再组合并复核实际 MP4。缓存校验失败会隔离失效素材并按当前场景重建一次。首次修复后仍复现时，复核几何、驱动和切点，有新证据或可验证的方案就继续内部迭代。尝试开始重复且证据和结果没有进展时，明确缺失的依据，检查能否在保持知识准确和表达质量的前提下调整表达。已确认的核心错误须清除后才能作为技术合格片交付。

### 用户参与

在保持或提升视频质量的前提下，逐步减少诊断过程中用户参与、截图、详细指导及重复返工的次数和实际人工时间。Producer 根据每个问题实际收到的帮助记录最高参与级别。

| 级别 | 实际参与 |
| --- | --- |
| L0 | Codex 自主发现、定位和修复。 |
| L1 | 用户提示存在错误，Codex 诊断并修复。 |
| L2 | 用户指出大致时段或部件，Codex 完成后续诊断和修复。 |
| L3 | 用户提供错误截图，Codex 追溯部件和源代码并完成修复。 |
| L4 | 用户详细说明正确结构、动作原理和修改方法，Codex 实施并复查。 |

优先用已有资料、高清帧、局部观察和 Blender 求值解决问题。根据缺失的信息逐级缩小请求范围，能用大致时段或部件继续诊断时就从那里入手。需要用户判断时，提供具体疑点、时码、原尺寸帧或局部图、已核对的依据以及待确认事项。拿到截图或答复后，由 Producer 继续诊断、建模、动画、渲染及复查。按实际生产记录保留问题、用户输入、修法和实际 MP4 复查结果。比较可比案例的用户介入次数，其中提示、截图和详细指导分别计数，同时记录自主发现数、已自主修复数及待处理数、同错重修、实际人工时间、制作成本及成片质量。缺失或不可比的数据标为未知。用户保留最终观感验收和发布决定。

### 成片与观众检查

成片检查集中核对机构和科学表达、原创及素材许可、字幕、节奏、音画同步和混音。对照资料核实图解的变量、单位和适用范围，示意量与实测量用清楚的文字表达。核对图解、字幕和机构锚点的可读性，以及切回机构后能否认出图解所讲的动作。具备实际视听能力时完整观看和实听。程序检测用于定位问题。记录检查的实际范围，缺少观看或听审能力时提供待人工确认的成片和未验证项。交付成片 MP4 和实际配音文案。封面、报告和平台操作按用户本次需求处理。

保留用户手动调用的独立观众审核，只读实际成片。正式路径的 Producer 预演观察用于定位和复查问题，独立观众体验与平台结果按实际证据记录。检查两秒、五秒和全片，记录前十秒的实质知识、首个潜在赞评关时点、生活实用知识、内容推进、总结、收藏和系列价值。用具体时码说明四项内容特征、后段发现、过度删减或无效延长的段落，以整片内容判断时长是否合适。前两秒的候选改法独立保留。连续感知缺失时按实际覆盖标注 UNKNOWN。

运营复盘以作品、平台及发布龄期记录约 24 小时、72 小时和 7 天的实际快照。记录两秒跳出、五秒留存、平均观看秒数和比例、完播、赞评藏分享、归因新增关注，以及后台可得的曝光、点击和流量来源。历史部分记录可单独使用，按已取得资料核对上传版本和本地制作绑定。以周、领域和平台看组合与同龄结果，记录每项样本量，并按可得片长、开场表现和流量来源检视混杂。领域试验可调整，单个作品用于提出假设。结合片长、内容深度、镜头表达和后台诊断提出下一题的可验证假设。后台确实展示时记录精选标记、精选反馈及明确提供的额外流量扶持，缺失项留空。只有后台提供时间分布时，才用相应时间粒度对照成片。沿用 [发布后复盘模板](douyin-post-review.md)。
