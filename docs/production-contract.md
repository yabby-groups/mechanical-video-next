# 「君哥拆机器」制作契约

持续制作准确、好看、易懂的机械拆解与原理视频。每集以一条完整的可播放成片作为交付。选题、资料研究、文案与分镜、模型与动画、配音与字幕、剪辑与混音、成片检查围绕同一条片子推进。

## 选题、文案与画面

- 尊重用户指定的对象和范围。选定可核实的具体型号，用原厂、维修、实物拆检等资料核对外观、装配、关键接触和运动。记录来源和实际查到的范围，给教学简化明确边界。
- 旁白、镜头和动作一起编排。用拆解交代零件位置，用有依据的连续三维运动展示关键因果。按需要使用剖视、特写和运镜，让观众看得到操作、传动、结果和必要的回程。一个题材可以讲多个相关知识点。
- 优先检查可复用的同型号资产和许可证。需要建模时沿用 CAD、EAS 或 Blender，保存源文件。其他作者的作品默认用于参考。有复用许可的素材按许可和需要剪入。
- 文案说人话，字幕用实际配音文本。片长随讲解、配音和必要的观察时间决定。采用 1920×1080 横屏、30 fps。

## 开场选择

研究时找出具体型号上最有看头的现象、观众平时看不到的结构及可保留的产品识别线索。给第一帧一个明确的观看目标。可以用内外同步、局部透视、状态对照或近景展示真实关系。若用静态整机、慢转台、推进、日常演示或旁白起问，说明它具体提供了哪条值得追看的线索。

正式制作前复用相机、模型、镜头缓存或低分辨率渲染做开场动稿。有影响选片的不同构想时，比较实际两秒与五秒预演。用前两秒已出现的画面说明观众为何想看第三秒，同时检查静音和手机可读性。用第 2–5 秒判断是否兑现或推进了开场线索。把选定的可见现象、构图和衔接落实到分镜、旁白和剪辑。检查点用于观察，镜头时长由表达决定。

## 制作和交付

当前会话负责完整成片。可将复杂机械核证、CAD、动画或实际视听检查交给现有专长角色。同一问题以已有证据和实际制作文件交接。

新片使用 [README 中的正式入口](../README.md)。该入口读取本集已编排的旁白、镜头与剪辑参数，调用现有 Neil、Blender、Remotion 和 FFmpeg。用实测语音时长安排字幕和镜头，配上清晰可闻的 BGM，按画面需要放入拟音。修改旁白、配乐或画面时复用未受影响的镜头，并检查实际更新的片段和连接处。对确认可再生的中间帧及时编码并清理。

成片检查集中核对机构和科学表达、原创及素材许可、字幕、节奏、音画同步和混音。具备实际视听能力时完整观看和实听。程序检测用于定位问题。记录检查的实际范围，缺少观看或听审能力时提供待人工确认的成片和未验证项。交付成片 MP4 和实际配音文案。封面、报告和平台操作按用户本次需求处理。

观众审核把两秒留存、五秒留存放在完播、点赞、收藏、评论和关注之前。前两秒的候选改法独立于整片修改清单。连续感知缺失时按实际覆盖标注 UNKNOWN，发布后的实际留存按对应平台数据记录。
