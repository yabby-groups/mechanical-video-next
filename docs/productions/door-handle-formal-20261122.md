# 门把手回正

**君哥拆机器**。拆开机器，看懂它怎么工作。用三维动画讲清身边的机械原理。

本集问题是「为什么门把手被按下之后，松手就能自动回到水平？」影片以室内压杆把手为观察对象，通过 US 7,900,978 B2 的一套具体弹簧回位设计回答。先让观众看见把手抬高，再沿着外力去哪了、弹簧推到哪里、什么决定水平位置三个发现推进。主线回到门外观察，正片保留最后一句机械答案。使用经验问题放在简介及置顶评论。

## 五项增长设计

- 完播从已安装把手的可见动作开始，第一个回答给到 13 秒以内。中段从端座靠实推进到簧圈压缩和主动回程。末段用止挡、壳体留位和整机复原收束。
- 点赞价值落在「一根压簧夹在两片拨片间，按下时只有一端主动走」的同框发现及回程的运动回报。
- 收藏价值来自末段完整三维剖视的去程和回程，能用同一组零件复习「方轴—拨片—弹簧」。
- 评论选一个主问题「你遇到过把手松手后回不到水平吗？当时它是慢慢回去，还是一直低着？」两种现象易于描述，反馈可用于后续证据查找。
- 关注建立在同一冷暖材质、先见现象再拆出机制及片尾完整兑现。简介邀请观众继续看身边五金的内部动作，不承诺尚未选定的下集。

### 动画与状态对照

- 拆解新增独立的轴向变换轨道，依次拉开把手、方轴、金色拨片和蓝色拨片。转角保持中位。随后用小景别呈现方孔与重叠顺序。
- 线圈对照使用同构图的回位端点与压缩端点，片上标明两个状态。原速压缩发生于 0:59–1:08，原速回程发生于 1:32–1:40。
- 片尾知识总结在静止的三维剖视上分段展示两条路线，画面用「按下」「松手」区分前后因果。完整回程已在前面的三维连续镜头交代。
- 右侧留空的用途限于图 3 所示开口，可供锁控连杆通过。源场景不包含完整锁控机构。
