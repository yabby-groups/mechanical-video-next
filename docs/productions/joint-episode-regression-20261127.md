## 时长、成本与观察边界

两题沿用 A 的完整片长，用来比较相同内容下的画面组织。扳手约 54–65 秒给留缝和接触移位保留观察时间，约 71–76 秒仍有相近构图。烤面包机 36.5–51.8 秒为较长的释放演示，51.8–65.8 秒的曲线、78–84.5 秒的高位持镜及 98.4 秒后的总结仍存在较长停留或重复。这一轮的新取景主要来自已有场景和原画面局部。烤面包机的简化操作在产品周围展开，两题的真实生活空间、独立新相机及 2.5D 成片效果留待其他题材验证。

- 活动扳手首次高清 1822.26 秒，含场景求值与渲染。缓存重跑 96.28 秒，复核后正式输出 74.66 秒，当前全长动稿 23.54 秒。
- 烤面包机候选重跑 159.02 秒，修正取消键构图后候选重跑 89.85 秒，调整图解切回三维的时点后候选重跑 79.75 秒，最大常驻内存约 1.77 GB。登记对应的成片证据后，正式输出耗时 81.23 秒。各次是本机生产命令的经过时间，包含 I/O、编码、复核以及可能的共享锁等待。
- 两个 B 的正式复跑分别命中 22/22 和 31/31 个逐句配音缓存。实际用户介入 0 次，L0。烤面包机分别修订取消键裁切和图解切点，同一问题重复返工 0 次。A 的完整实际工时和历史人工介入次数为 UNKNOWN。
