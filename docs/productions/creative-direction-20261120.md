# 生活科学创作方向验证

## 根因与变更

| 原来的决策 | 实际影响 | 新任务的处理 |
| --- | --- | --- |
| README、AGENTS 和 Producer prompt 对时长及灰色金属风格的描述互有冲突。CLI 已使用 v2，但 Producer 指令仍要求统一灰色金属风格并默认读取机械镜头配置 | 已经声明创意优先的任务，仍从最熟悉的机构、模型和相机入手 | `produce --topic` 默认 `science-story-v3`。Producer 从生活问题、可见变化和结尾回报选择风格。时长沿用联合时间轴，由成片决定 |
| `continuation` 先派资产，随后把冻结版 Blueprint 派给 ViralResearch。可执行 Blueprint 要求拆解顺序和外部表达原则，即使并无拆解 | 资产先锁定，研究和插图倾向围着零件讲。单片运镜调优没有改变下一个题的派工或模板 | 复用 `diagnostic-animatic`。先由 Producer 提交研究绑定的完整低成本动稿，再选资产。Producer 负责 Blueprint，Editor 负责完整视听节奏。v3 无必填拆解顺序、外部创意参考依赖 |
| `visual_narrative.validate_plan` 对所有视觉方案都要求机械核心镜头，包括明确标记的物理现象。资产和 QA 路径还默认找参考装配 | 内容计划需要为 CAD 找理由，纯光学等题材也会被拖回机械路径 | v3 有界物理现象可无机械核心镜头，保留证据、权利和完整媒体来源。机械主题继续要求可核验核心动作，既有科学和动画检查继续执行 |
| `check_qa` 在制作阶段允许创意 UNKNOWN，旧整片技术旁路可跳过普通动稿要求。多数测试只证明证据、结构或文件执行正确 | 工程结果可推进昂贵制作，但尚无法知道开头、节奏或结尾是否成立 | v3 正式渲染沿用精确文件绑定的 `animatic-qa` 并要求六项创意 PASS。节奏、镜头任务和视听判断必须覆盖完整编辑。正式影片的科学正确性与创意判断继续分别记录 |
| 内部知识目标自动写入合成 label，旧基础配置可继承公式和信息标注 | 创作人员可能把研究位置、工程假设和流程提示写成观众文案 | v3 不把知识目标复制到合成 label。可见公式和信息层由本集明确创作。保留题材必要术语、有意义的模型限制及许可署名 |

新任务继续使用一个 Producer、同一账本、不可变 handoff、联合时间轴和现有验收。实现沿用了工作区已有的自然解说、文字表现和联合时间轴变更。此次两个样片由当前 Producer 完成，未启动新的工作流或额外 Agent。

## 两个实际动稿

**肥皂膜为什么有颜色，后来又暗下去？** 27 秒。用暗场彩带和同一液膜的亮暗变化构成首尾呼应。0–7 秒膜内的条带移动并换色。7–12 秒显出两条反射路径，12–19 秒用一组行波展示由增强到抵消，19–27 秒回到原膜观察暗区扩大。0.5–6.5 秒的膜内区域及 12.5–18.5 秒的合成波区域各有 180 帧，逐帧内容哈希均不同。颜色由三条代表波长和编排的膜厚场生成，适用结论是颜色随膜厚改变及极薄处反射变暗。模拟的排液时间和颜色不用于定量解释。正式制作暂缓。光线与波形段落占近半，是否需要两次切到解释图，以及如何更自然地带回肉眼现象，要经连续观看判断。[样片](../../output/creative-direction-20261120/soap-film-v2.mp4) · [任务账本](../../output/tasks/science-story-soap-film/task.json) · [OpenStax 薄膜干涉](https://phys.libretexts.org/Bookshelves/University_Physics/University_Physics_\(OpenStax\)/University_Physics_III_-_Optics_and_Modern_Physics_\(OpenStax\)/03%3A_Interference/3.05%3A_Interference_in_Thin_Films)

**电子纸不用一直刷新，字怎么还在？** 25 秒。暖绿平面插画从阅读器翻页切到「雨」字，再下探到双色微胶囊。6–10 秒从雨字放大到像素，10–19.5 秒用粒子对向换位写出中间两处的深色，19.5–25 秒回到同一页。第二版用真实字形采样替代通用格子，并把极性提示移到电极侧。12.2–16.4 秒粒子区域从 126 帧得到 123 个不同内容哈希。22–24.9 秒屏内文字区域的 87 帧有同一个内容哈希，保留这个静止是为了回答开场问题。解释范围限双色微胶囊技术，设备外观是原创插画，屏幕留图也不等于整台设备停止耗电。正式制作暂缓。像素到胶囊仍是硬切，极性提示在手机上偏小，电场与笔画的连接需做连续视听验证。[样片](../../output/creative-direction-20261120/electronic-ink-v2.mp4) · [任务账本](../../output/tasks/science-story-electronic-ink/task.json) · [E Ink 双色粒子](https://www.eink.com/tech/detail/How_it_works) · [E Ink 双稳态](https://www.eink.com/tech/detail/Benefits)

两个样片均为 960×540、30 fps 的 H.264/AAC，FFmpeg 完整解码通过。短字幕和原创程序声音用于动稿，旁白尚未录制。来源网页只用于科学研究，成片试验中的图像、动画与声响均由预览源码产生。两条任务通过原有 `produce` 和 handoff 登记，状态仍是 `RESEARCHING`，各有两个不可变动稿版本。逐帧解码与画面抽查支持上述观察。独立连续观看、听审、真实观众理解、正式渲染及交付验收仍待验证。[可重放源码](../../output/creative-direction-20261120/render_studies.py)
