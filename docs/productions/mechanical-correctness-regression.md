## 正式入口与修复责任

声明了 `mechanics` 的镜头先进入 Blender 装配检查，再使用原渲染的姿态函数，从依赖图测量实际求值的变换、网格表面和弹簧端点。正式剪辑的全部三维区间按每帧两至四个采样步求值，剪辑另检查声明的方向、步长、事件和连续切点。每个镜头生成一段连续八帧的低成本预演。高清重建场景对照同一预检状态，编码镜头与预演作该窗口的画面对照。最终 MP4 按帧对照相应源区间，已确认错误会阻止候选替换。凭证记录实际 MP4、剪辑、源画面、场景依赖、求值和音频哈希。

- **活动扳手**检查滚轮轴及固定关系、活动钳口导向、有向导程和行程。演示采用单头等距啮合原理。 [研究资料](../../productions/adjustable-wrench/research.md)
- **抽屉滑轨**检查相对行程、保留搭接、导向和保持架相对于轨道的半速关系。 [研究资料](../../productions/drawer-slide/research.md)
- **弹跳烤面包机**检查托架与吐司的有符号接触间隙、滑架导向、弹簧挂点和回程，以及取消触发和滑架上升的顺序。接触使用实际求值网格上的射线交点。 [研究资料](../../productions/pop-up-toaster/research.md)

程序自动隔离内容失配或缺凭证的高清缓存，并在本次调用内用当前场景重建一次。模型、驱动和剪辑根因由当前 Producer 根据定位结果修复。随后复用未受影响的素材，局部重渲或重剪，并复核新 MP4。每镜头的 Blender 预检和高清调用分别设有 300 秒与 1,800 秒超时。制作契约将同一错误的根因修复预算设为两次，第二次采用不同策略。

## Blender 动态结果

使用 Blender 5.3.0 运行真实生产场景。五个正常用例通过，六个模型或动作故障按预期被定位。实际高清素材的剪辑回归拦截了错接，通过了连续剪辑。历史 Blender 约束回归另外通过 26 项。

| 扳手滚轮速比减半 | 镜头 0.2000 秒，有向导程失配 |

按实际 Neil 时长预检三套正式剪辑。活动扳手 7 个三维镜头求值 5,601 个姿态，抽屉滑轨 5 个三维镜头求值 3,463 个姿态，烤面包机 8 个三维镜头求值 11,980 个姿态。三个题材均通过所登记的求值检查。烤面包机的二维曲线语义覆盖为 `UNKNOWN`，成片时间为 51.766667–65.800000 秒。取消演示的八帧短预演落在有意状态切换附近，滑架释放顺序的断言覆盖整镜。扳手和滑轨完整剪辑的本轮验证覆盖至渲染前检查。

本地逐用例和完整剪辑结果保存于 `work/mechanics-dev/cases/results.json` 和 `work/mechanics-dev/full-preflight/results.json`。Python 测试共 638 项，630 项通过，8 项跳过。工作区保留素材超出默认 2 GiB，635 项运行时临时使用 8 GiB，另三个预算相关测试在恢复默认环境后运行。完整日志在 `work/mechanics-dev/unittest-final.log`。 [Blender 回归脚本](../../tests/episode_mechanics_blender.py)

## 从发现到最终 MP4

1. 在正式入口的活动扳手回归副本中反转蜗杆。预检定位到 0.2000 秒的有向导程错误。Producer 修复滚轮驱动符号后重新求值 733 个姿态，在同一场景渲染高清镜头，使用 Neil 缓存和原 BGM 重合成。367 帧全部通过源画面对照。抽看 0.50、1.25 和 3.65 秒可见滚轮参照线、活动钳口及固定基准的相对变化。
2. 以同一高清素材剪辑两段，将第二段错误接回源帧 0。正式入口发现切点钳口跳变 0.31。将第二段改到源帧 110，复用高清画面和 Neil，230 帧全部通过源画面对照。抽看 3.60、3.70 秒，钳口和滚轮标记在切点附近保持同一状态。
3. 在独立工作目录改动一个已核实高清缓存的字节，保留原凭证。正式入口发现哈希不符，隔离缓存及凭证，仅重渲该镜头，然后复核合成的 367 帧。原回归片和原素材均保留。
4. 在烤面包机原开场复现旧网格的接触错误。正式入口在第 0 帧测得 +0.024 的间隙并停止。Producer 删除吐司底面多出的高度偏移，沿用 ±0.002 的检查范围。重算 1,369 个姿态，最大绝对间隙约 0.00000012。复用开场 Neil 旁白、字幕时序和 BGM，重渲并对照全部 343 帧。抽看 0.00、0.80、1.53 和 4.00 秒，可见两片吐司随两条横托上升，并看到两条横托接到同一个滑架。拒绝记录和修复日志保存于 `work/mechanics-dev/toaster-baseline.log` 与 `work/mechanics-dev/toaster-fixed.log`。

## 证据边界

活动扳手的原型弹簧与内部尺寸、滑轨样件的止挡接触与实测行程、烤面包机内部锁扣和电控信号仍需非专利实物资料。当前片例采用已有证据支持的示意范围。运行时自动检查覆盖所声明的机械关系和剪辑操作，未声明机械测量的历史镜头显示 `UNKNOWN`。小尺度零件的遮挡、箭头指向、旁白语义、二维曲线与三维状态是否一致，以及未声明的齿面接触需要 Producer 结合实际画面和来源复核。机械事实未知、模型或动作失败、剪辑错误与感知覆盖的结论分别记录。
