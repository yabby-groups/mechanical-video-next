# 关键机械接口复查与人工参与记录

基线为 `bf1b172`。上一轮真实盲测中，门锁斜舌和阀芯出水口在 A、B、C 三组均为 0/2 确诊、0/2 定位、0/2 修复。本轮把资料中可观察的机械预期提前到建模前，动稿阶段核对相邻件、关键中间姿态及结果的出现顺序。原有机械求值、取帧、映射和局部渲染已用于本轮检查。 [首轮盲测](visual-mechanical-diagnosis-20261126.md) · [制作契约](../production-contract.md)

## 两项已知失败回归

- **门锁斜舌与扣板。** 原 QA 看过 43.93 秒，用户截图约在 43.8 秒。旧检查关注回缩和把手姿态，缺少一项具体判断，即门扇关闭时哪个面首先碰扣板、该面能否把斜舌推回。原厂安装图明确要求斜面迎向扣板。对同机位两版各取 85 个姿态，间隔四分之一 Blender 帧。让斜舌保持伸出以识别潜在受力面，旧版在 1221.00 帧首次与扣板唇相交，命中面世界法线约为 `(-0.112, 0.994, 0)`。改向版在 1229.25 帧首次相交，法线约为 `(-0.850, 0.527, 0)`，沿斜舌滑动轴的分量更大。实际动画两版首次非零回缩分别出现在 1220.25 和 1228.25 帧，取样中未出现实际动画网格与扣板唇相交。该求值区分了两版的迎向及最先可能受力的表面。实际连续接触、入孔与弹簧状态仍有待核实。 [旧场景求值](../../work/interface-check-study/known/door-before.json) · [改向场景求值](../../work/interface-check-study/known/door-after.json) · [同机位片段](../../work/visual-diagnosis-study/history/door-same-camera/first-contact.mp4)
- **阀芯壳壁与出水接口。** 审核者看出了实片的侧管和科勒照片侧窗的差异，因完整水路缺证而搁置判断。科勒换件照片可直接核对可见的壳壁窗口。原镜头把窗口画成伸出阀芯的独立短管，改变了所讲述的接合边界，现有资料未给这项差异提供教学简化依据。约 3 秒的历史修复画面已经显示壳壁窗口，32.67 和 34.67 秒的对照展示了水从窗口进入阀体的示意。责任网格是 `Bored outlet with open cut face` 和相邻壳体，历史修复提交为 `823a09d`。开口尺寸、不可见侧和内部全程仍属待核实。 [科勒维修说明](https://assist.kohler.com/en/bathroom-faucets/Replace-the-Valve-in-a-Two-Handle-Faucet) · [原 MP4 取帧和映射](../../work/visual-diagnosis-study/history/faucet-opening/visual-diagnosis.json) · [历史动态对照](../../output/quarter-turn-faucet/阀芯出水口-前后对照.mp4)

两个答案在本轮检查前已经公开。门锁记录支持首次接触面核对缺失，阀芯记录支持局部结构差异未进入独立判断。现有记录无法区分审核范围宽度、采样密度和注意力分配各自的影响。

## 新案例的独立盲审

审核者在抽看样片前，用公开的非专利资料写出局部机械预期。输入材料为匿名的历史削皮器片、扳手缓存片段及对应场景。审核前未获得用户提示、截图、错误位置或历史修法。削皮器看过每 3 秒的总览及七张原尺寸画面，扳手看过 0、6、12、18、24 帧的原尺寸画面。审核者还读了相关场景和驱动代码，冻结初判后再对照历史反馈。 [事前预期](../../work/interface-check-study/review/c-evidence/expectations.md) · [冻结初判](../../work/interface-check-study/review/findings.md)

| 削皮器新发现的首刀前提前露肉 | 1 | 1 | 1 次局部修复，编码对照已复查 |

削皮器的先验写出了刀口必须接触果面以及果皮应从接触区域离开。盲审检查到了这条时序，但没有把原厂操作方向、刀刃与导向面的朝向、实际相对行程连续对照。对苹果也没有用资料比较轮廓、果蒂凹陷和果皮表现。原厂演示覆盖仅为采样，现有记录无法判定更完整的资料或连续检查能否检出这两个历史问题。历史修复 `0f3211f` 改动了苹果、刀口及行程，并已在本机保留对应完整修正版。该修正版在 0 秒和约 0.63 秒的编码画面中也没有提前出现在悬空刀具下方的白色切痕。 [历史修复](https://github.com/yabby-groups/mechanical-video-next/commit/0f3211fd07ff8a81616b017c919609d3acd0d45f) · [历史修正版取帧](../../work/interface-check-study/revised/)

新发现的问题出现在原片 0 秒。苹果表面先出现露肉条，刀刃与果面仍有可见空隙。原场景 `in_use` 中的 `gap` 和 `expose` 独立更新，`Newly exposed apple track` 提前绘制。审核者把露肉起点锚定到接触姿态，接触前将露肉长度置零。修复沿用同一相机和刀具运动。两段编码媒体按原片时间 0–2.0 秒每 0.2 秒取样，各 11 帧，960×540。解码复查显示首帧的露肉条消失，0.6 秒刀具下降后出现浅色轨迹，2.0 秒果皮仍可见。修复片是无字幕、无音频的 5 fps 局部动稿。刃口全程接触、全片质量及听审仍未核验。 [修复代码与证据记录](../../work/interface-check-study/repair/README.md) · [同机位对照 MP4，左原片右修复](../../work/interface-check-study/repair/comparison.mp4)
