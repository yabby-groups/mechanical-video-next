# Editorial composition audit

The existing visual-policy timeline composes licensed footage or original information graphics alongside native 3D shots, narration and subtitles. The science overlay uses projected per-frame anchors for labels, sampled values and a crop of the same source for an inset. Graphics support diagrams, comparison, charts, timelines and formula text; chapter cues and cuts are available. The existing source, license, evidence and provenance checks remain required for production.

The timeline adds a two-source split screen and `data_animation` with independently interpolated numeric keyframes and a common scale. `split_screen.sources` holds exactly two existing footage objects; the first is also `footage`. Both require their own validated license, source hash, attribution, start frame and sufficient duration. Both source files and public cache copies are rehashed by the Remotion proof. Data animation takes `title`, `unit`, optional `formula` and `domainMax`, and two to four items with `label`, `detail`, and ascending `[seconds,value]` `keyframes`; the compiler must bind those values to research evidence. New chart and split-screen credit text uses a minimum 64 composition pixels and browser overflow checks; `validate_phone_text` supplies a preliminary measurement. Existing standard graphics retain their historical type sizes and require actual 360/390/430 px review. Inter-shot animated transitions remain unavailable.

Verification: `npm run typecheck` and 16 unit tests passed. A local Chrome/Remotion smoke render produced a 2-second, 60-frame, 480×270 MP4 from two synthetic colored clips followed by an animated data graph. This checks that the components execute on one short timeline; it does not establish rights, perceptual acceptance, or continuous observation of production media.
