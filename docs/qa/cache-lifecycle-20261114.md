## 使用

```sh
uv run python scripts/clean.py --dry-run --expired --report
uv run python scripts/clean.py --dry-run --pressure --report
uv run python scripts/clean.py --task TASK_ID --dry-run --report
uv run python scripts/clean.py --expired --apply --report
```

默认不删除。`--auto` 沿用原生产启动入口的安全自动模式；`--dry-run` 优先于执行标志。锁忙时返回 SKIPPED 和删除 0 字节，不绕过正在运行的制作。QA 原尺寸及每轮图片数量规范保持原样。

## 恢复与缓存身份

分块清单保存实际帧序列、尺寸、fps、分块长度和 MP4 SHA256。恢复同一内容寻址目录内失败会话时先复核已成功分块 SHA256 并完整解码，复用成功分块；失败分块重新制作。损坏分块保留现场并停止，不冒充可恢复。

`config/cache-code-equivalence.json` 精确绑定本次维护源码与原源码哈希。只有完整文件完全匹配维护版本才沿用旧媒体缓存身份；后续任意改动自动失配，不掩盖后续渲染变化。测试比较 Blender 除维护函数之外的全部函数 AST。风格锁仅刷新 scene.py 的维护哈希，原截图、风格、几何、运动与配音未改变。
