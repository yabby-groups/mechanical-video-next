# Quiet Link

The four Quiet Link recordings were composed for this project in
[scripts/generate_starter_music.py](../../../../scripts/generate_starter_music.py).
The generator writes a melody, chord accompaniment and bass part as synthesized
oscillators. It uses no samples, third-party recordings or music-generation services.
The catalog binds the exact distributed FLAC bytes and this rights statement by SHA-256.

The Quiet Link composition and the four recordings in this directory are dedicated
to the public domain under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The dedication covers commercial synchronization, editing, looping and distribution.
Credit is optional. The software generator follows the repository software license.
