# 门把手为什么会自己回正？

按下门上的把手。放手之后，观察把手从斜向下回到水平。影片接着沿同一把手拆开饰盖与底座，让观众看到中间的方轴、轴上两片拨片和沿左侧弧形槽布置的压簧。

按压时，方轴的棱带动金色拨片。蓝色拨片停在固定侧。金色拨片把弹簧的一端向蓝色侧推近，圈距缩小。在同一机位放手，弹簧推回金色拨片。这个力和轴心有距离，所以产生回转力矩，方轴和把手跟着回到水平。

回到完整把手再次演示，动作在回到水平时停住。一只手施加向下转矩，弹簧储存的弹性势能提供回程。核心动作来自同一原生三维场景。

## 分镜

| 时间 | 画面和观察点 |
| --- | --- |
| 0–5.3 秒 | 门上安装的杠杆把手完整按压和回正，门板给出固定水平参照。 |
| 5.3–14 秒 | 斜视爆炸拆解，沿轴区分方轴、金蓝拨片、弧形压簧和外壳。 |
| 14–23.6 秒 | 切到接近正面的剖视，看到方轴转动、金色拨片追着压簧端推进、另一端保持。 |
| 23.6–33 秒 | 镜头延续同一个按压位置，观察压簧伸长，金色拨片、方轴和把手回程。 |
| 33–40.5 秒 | 回到安装外观，按压和回正重演让观众再识别输入与回程。 |

实施例采用可查证的 US 7,900,978 B2 图 1–5。在图 3 和对应说明中，两片拨片都位于初始位置。图 4、图 5 对照显示按不同方向只有其中一侧压紧同一根压簧。影片沿一个下压方向解释。零件尺寸、配色和动作时间服务于展示，按压角度与回位速度没有实物测定。锁舌传动和关门扣合留在本集范围之外。 [专利原文](https://patents.google.com/patent/US7900978B2/en)
