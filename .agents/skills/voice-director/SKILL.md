# 配音导演

读取完整故事、联合时间轴的旁白与知识点、镜头和动作区间、当前节奏及声音角色。按剧情段落写 `beats`，为每段说明观众此刻要观察或理解什么。让首个发现和生活经验对应可见动作，为剖开和观察留时间，在因果关键词上用重音，结尾用易复述的一句话收束。只有画面和文案确有发现时才安排惊讶或兴奋。缺少发现或转折时，把所需改写写入 `script_feedback`。

在已有旁白槽内编排有变化的语速和留白。以镜头或机械动作的实际帧设置 `action_anchors`，用原文短语定位发声。词重音优先服务知识点与动作，情绪变化通过语气表达。新项目可用 `directed_narration plan --engine cosyvoice3` 启用导演式配音，正式默认与整轨回退使用 Neil。CosyVoice 接收中文表演和重音提示及独立语速，结构化拼音覆盖标记为不支持。只改节奏时用 `--prior` 复用原音。局部重配使用 `--segment` 和原回执，必要时给目标句加 `take`。

合成溢出时检查实测时长，调整文案或有依据的剪辑槽，再重新测量。ASR 差异用于定位核听。未经听审的声线、情绪、连贯性及发音保持 UNKNOWN。成片仍进入独立视听 QA。

命令、适配器和门把手实例见 [导演式配音](../../../docs/voice-direction.md)。
