# 自动生产审片

## 独立机械与视觉审查

对 `music_direction_version=1` 的最终 MP4，核对生成的技术音频结果和 `audio_direction.json`。在当前独立 `final-qa` 记录 [音乐听审](../../../docs/audio-direction.md) 的准确区间、剧情适配、语音、拟音、开头、揭晓、过渡和结尾。缺少实际听审时记录 `UNKNOWN`。

正式影片先核对任务固定的时长版本、片种和精确媒体哈希。v2 按完整因果选择时长，上限 300 秒。v1 保留 120–300 秒，按时间码检查每段知识增量及回放标识。把五项增长设计的观察绑定到原生三维、音画与发布素材。连续机械观察、技术测量、持续视听、真实首次理解和发布后指标记录各自的证据与覆盖。

比较同一机械状态的实际媒体，记录材质和灯光层级、装配空间线索、镜头观察任务及输入到结果的可见性。微距裁走上下游参照时，定位具体镜头并复核相邻切点。见 [实际审查案例](../../../docs/productions/cinematic-3d-20261122.md)。

用现有 QA 核对用户指定对象和核心问题、内部三维几何、可观察的连续运动、输入到复位的科学因果、辅助内容的作用，以及是否兑现「拆开机器，看懂它怎么工作。用三维动画讲清身边的机械原理。」确认换题、偏离定位或以二维替代核心三维机构时判 REJECT。用实际 MP4 和原生几何查接触、穿模、自交、掉帧与中途跳转。局部问题位于具体镜头时判 REVISE，整片缺失连续证据时记录 UNKNOWN。独立机械和视觉均 PASS 后可进正式制作。见 [制作契约](../../../docs/production-contract.md)。

由现有 QA 执行。读取 [制作契约](../../../docs/production-contract.md)、当前任务及对应的 `animation-manifest` 或 `timeline`。从同一交接的 `video_review` 读取实际 MP4 哈希、技术结果、时间码和证据。历史媒体可用 `uv run python -m mechanical_video_next.video_review MP4 INPUTS --output REPORT` 以实物单独诊断。

1. 先记录当前工具能连续看到和听到的区间。实际连续播放时按原速审全片，复核关键动作的连续片段。静帧走 `qa_images`，每轮最多四帧和一张联系表。在报告中标记时序帧、技术测量及 UNKNOWN。
   历史媒体缺交接时，可运行 `uv run python -m mechanical_video_next.video_review MP4 --output REPORT`。报告按精确文件哈希记录全片解码定位的静止画面、黑场和音轨低电平区间。对照播放器中的动作和讲解复核这些区间。机器播放进度和音轨测量分别记录。
2. 沿同一个动作比较施力、传动、接触前后、复位和结果。检查相邻切点的共同零件、运动方向、坐标参照和状态。换机位后确认状态接得上，复演或第二个实验的重置应在影片中可辨认。复核小件、遮挡、穿插和关键状态停留。
   对导演整改，用完整新旧片核对观看节奏，再用同源帧对齐的动态片核对构图。无旁白、无字幕版用于核对观众从画面能读出的传动。定点抽样分别记录遮挡、接点参照和状态差。观众首次理解及连续体验按实际审阅覆盖登记。
3. 把实际声画按同一播放轴对齐。用原始 Neil 音轨、字幕窗和实际运动窗口定位讲解和接触。实听缺失时按任务的 Neil 规则记录技术音频验收和感知 UNKNOWN。用 ASR 定位疑点。
4. 复述本片提出的问题和最终解释。逐项查看必讲知识、可见证据、结尾与故事承诺。检查是否因裁切、重映射或配音缩短丢失了必要步骤。按当前交接字段记录机械事件、故事节点、能力边界与实际观察。
5. 每项问题给出实际时间区间、镜头、现象、严重程度、责任、最小修复和复核方法。Producer 修复后，先复查变更片段及其切点，再核查更新后的完整片。使用新 MP4 哈希写入现有独立 QA。

v2 正式片读取现有 Video Review 随精确 MP4 生成的 pacing 报告。用 pacing_checks 记录开场有效事件、首次结果和答案、等待、运镜、重复、动作速度、音画同步与完整知识推进。使用实际连续观看和实听给出感知结论，缺少证据时为 UNKNOWN。
